\title{When Interface Formatting Changes Model Answers}

\author{Anonymous Author(s)}

\begin{document}

\maketitle

\begin{abstract}
Language models often receive questions through tables, forms, configuration files, and other structured interfaces. We test whether changing only this formatting changes whether a model answers the same multiple-choice question correctly. We evaluate three instruction-tuned model families---Qwen2.5-1.5B, Phi-3.5-mini, and Mistral-7B-v0.3---on 3,000 MMLU items rendered through eight wrappers intended to preserve the question, answer choices, and labels while changing syntax and layout. Across 72,000 wrapped prompts, calibrated accuracy is 48.4\%, 56.8\%, and 50.3\%, respectively. The fraction of items answered correctly under at least one wrapper and incorrectly under another is 62.0\%, 55.1\%, and 66.2\%. We then test a simple mechanistic hypothesis: successful runs may form an internal activation vector that identifies the real question and options despite the wrapper. Across all three models, successful and failed wrappers have similar content attention, and activation patching is stronger for some answer-label-matched cross-item donors than for same-item successful donors. If a wrapper-independent task state exists, these probes did not isolate it.
\end{abstract}

\section{Introduction}

Structured prompts are not only cosmetic for language models. A model can see the same question and the same answer choices inside different interface syntax, then answer correctly in one format and incorrectly in another. This matters for deployed systems because many tasks arrive as CSV rows, HTML fields, configuration files, tool traces, or API-shaped records rather than as plain prose.

We study this effect on multiple-choice MMLU questions. Each item is rendered in several wrappers that keep the same question, the same four answer choices, and the same answer letters. Only the surrounding format changes. We score the next answer letter directly, so the result is about which option the model assigns the highest likelihood to, not about how it explains itself.

The mechanistic question is whether successful wrapped prompts share a simple internal state. Our hypothesis was that the model might strip away the wrapper formatting, identify the real question and options, and form an internal activation vector that can be used for answer selection. We test that idea at semantic positions in the prompt: after each answer option and after all answer options have appeared.

The behavioral result replicates across all three models. Interface wrappers produce item-level conflict rates from 55.1\% to 66.2\%, despite large differences in model family and calibrated accuracy. The mechanistic result is a modest negative one. Attention to question and option tokens is almost the same for successful and failed wrapped prompts. Successful wrapped prompts become only slightly more similar, by cosine similarity, to the unwrapped prompt activation. Activation patching sometimes helps failed runs, but the strongest average recovery in the two replication models comes from cross-item donors that share the answer letter, not from the same item's successful wrapped run. If the models form a wrapper-independent task state, these diagnostics did not isolate it.

\paragraph{Scoring and calibration.}
For each wrapped prompt, we score the conditional likelihood of answer letters A/B/C/D at the answer position; the raw prediction is the highest-scoring letter. Some wrappers make one answer letter more likely even when the question and options are removed. We estimate this wrapper letter bias by scoring a content-free version of the same wrapper, produced by removing the question and option text while preserving the wrapper structure. The calibrated score for a letter is its wrapped-prompt score minus this content-free score. The calibrated correct-answer margin is the calibrated score of the correct letter minus the largest calibrated score among the three incorrect letters; a positive margin means calibration favors the correct answer.

\paragraph{Conflict construction.}
The behavioral analysis reports the full 24,000 scored rows for each model. The original Qwen analysis additionally reports a primary calibrated set of 18,577 rows over 2,672 items. The full set uses same-wrapper content removal where available and fallback calibration otherwise; the primary set keeps only rows where same-wrapper content removal succeeded. An item-level conflict means that at least one available wrapper is correct and at least one available wrapper is wrong for the same underlying item. After this point, a \emph{successful wrapper run} means a wrapped prompt whose calibrated answer is correct, and a \emph{failed wrapper run} means a wrapped prompt whose calibrated answer is incorrect. For mechanistic tests, each eligible validation item contributes the strongest successful wrapper run and the worst failed wrapper run after calibrated scoring. This yields 285 Qwen, 264 Phi, and 300 Mistral validation-split conflict pairs. The construction is item-clustered, so multiple wrappers of one question are not treated as independent evidence.

An outcome-blind model-assisted row audit followed by a separate adjudication pass found 107 prompts that changed task content and four ambiguous prompts among the 24,000 source rows. Removing those 111 rows leaves all 3,000 items represented and yields conflict rates of 61.5\% for Qwen, 54.8\% for Phi, and 66.1\% for Mistral. The behavioral conclusion is therefore not driven by the identified wrapper defects, although the source set is not perfectly pure-interface.

\paragraph{Mechanistic diagnostics.}
The main anchors are \texttt{options\_end}, the token position after the final answer option, and \texttt{all\_option\_ends}, the collection of positions after each answer option. Attention diagnostics measure mean attention mass from these anchor query positions to token roles. The content-attention measure is attention to question tokens plus attention to option tokens. This is descriptive, not causal. Activation-vector similarity measures cosine similarity between a wrapped internal activation vector at the anchor and the corresponding activation vector in the same item's unwrapped prompt.

\paragraph{Causal controls.}
Activation patching is the causal intervention used here: we copy activation vectors at the selected anchor from a donor run into an originally failed target run and then rescore the target \citep{meng2022locating,wang2022interpretability,zhang2024activationpatching}. Patched accuracy is the fraction of originally failed targets that become correct after patching. Mean margin improvement is the patched correct-answer margin minus the original failed-run margin. Mean recovery is the fraction of the successful-minus-failed margin gap closed by the patch, where 0 means no recovery and 1 means the patched margin reaches the successful-run margin. Donors include the same item's successful wrapper run, the same item's unwrapped prompt, cross-item successful wrapper runs, cross-item successful runs with the same correct answer letter, and cross-item successful runs with a different correct answer letter.

\paragraph{Compute.}
The final Qwen focused mechanistic run used one NVIDIA RTX A6000 GPU with 47.4 GiB reported memory on Ubuntu 22.04, CUDA 13.0, Python 3.10.12, and PyTorch 2.12.0. It ran from 2026-05-31 01:39:05 UTC to 02:10:58 UTC and reused full behavioral scores from a prior validated run on the same GPU class. The Phi and Mistral replications ran sequentially on one 48GB-class RTX A6000 under Linux 6.8, CUDA 12.6, Python 3.10.12, and PyTorch 2.7.1. Their measured full GPU-phase times were 80.8 and 119.2 minutes, respectively, including behavioral scoring, convergence, controls, and attention diagnostics.

\section{Wrapper-Induced Answer Instability}

Pure interface changes substantially affect answer correctness. On the full 24,000 prompt set, calibrated accuracy is 48.4\%, raw accuracy is 47.3\%, and wrapper-level calibrated accuracy ranges from 43.0\% for \texttt{csv\_inline} to 52.5\% for \texttt{key\_equals}. Across all 3,000 items, 62.0\% are conflicts: the same model answers the same question correctly under at least one wrapper and incorrectly under at least one other wrapper. Only 17.4\% are answered correctly under all eight wrappers, and 20.6\% are answered incorrectly under all eight wrappers.

\section{Content Attention Does Not Separate Success from Failure}

If wrapper failures were mainly failures to attend to the real task content, successful wrapper runs should allocate more attention to the question and answer options than failed wrapper runs. We do not observe this at the coarse token-role level. For \texttt{all\_option\_ends}, the average absolute successful-versus-failed difference in content attention is 0.0046 across layers. For \texttt{options\_end}, it is 0.0052. The largest observed successful-versus-failed content-attention gap in the summary table is 0.0189, at \texttt{options\_end} layer 27.

The comparison to unwrapped prompts is different. Unwrapped same-item prompts allocate much more attention to question-plus-option tokens than wrapped prompts. The mean unwrapped-minus-successful content-attention gap is 0.359 for \texttt{all\_option\_ends} and 0.338 for \texttt{options\_end}. For example, at layer 4 under \texttt{all\_option\_ends}, successful-run content attention is 0.337, failed-run content attention is 0.335, and unwrapped-prompt content attention is 0.875. Thus wrappers strongly change attention allocation relative to a direct prompt, but success and failure among wrapped prompts are not separated by a simple content-versus-wrapper attention split.

\section{No Simple Wrapper-Independent Activation Vector Appears}

The activation-vector similarity comparison is weakly aligned with the hypothesis, but too small to carry the claim. At both anchors, successful wrapped prompts are slightly closer to the same item's unwrapped prompt than failed wrapped prompts are. The layer-mean successful-minus-failed cosine similarity delta ranges from 0.0047 to 0.0104 for \texttt{all\_option\_ends} and from 0.0035 to 0.0076 for \texttt{options\_end}. The direction is consistent with the idea that successful wrappers become more similar to the unwrapped prompt activation, but the effect size is tiny.

The causal controls are more diagnostic. Same-item successful-to-failed patches are weak: the best \texttt{all\_option\_ends} patched accuracy is 13.0\%, at layers 14 and 16, and the best \texttt{options\_end} patched accuracy is 4.9\%. Same-item unwrapped-to-failed patches are also weak: the best \texttt{all\_option\_ends} patched accuracy is 11.2\%, and the best \texttt{options\_end} patched accuracy is 5.3\%.

The strongest effects do not come from the donors predicted by a simple wrapper-independent state account. Same-answer-letter cross-item donors reach 20.4\% patched accuracy at \texttt{all\_option\_ends} layer 4, with average recovery 0.188 across layers and maximum recovery 0.244. Different-answer-letter cross-item donors also improve some cases, reaching 16.5\% patched accuracy at layer 6. This pattern suggests that patching transfers answer-letter-related structure. It may still reveal transferable computation, but it is not evidence for a wrapper-independent state that extracts the task from the formatting.

\section{Replication in Phi-3.5-mini and Mistral-7B}

The behavioral effect generalizes to the two larger replication checkpoints. Across the full 3,000-item population, Mistral has 50.3\% calibrated accuracy and 1,987 conflict items (66.2\%); Phi has 56.8\% calibrated accuracy and 1,654 conflict items (55.1\%). Thus higher average accuracy does not remove interface sensitivity: even for Phi, more than half of the source questions cross the correct/wrong boundary under wrapper changes.

\section{Discussion and Limitations}

The study supports a behavioral claim and does not support the simplest mechanistic account. The behavioral claim is that wrappers intended to preserve the task can change whether an instruction-tuned model answers the same MMLU question correctly. This is not driven by the small set of audited defects: the sensitivity analysis removes them, scoring uses answer-label likelihood rather than generated prose, and calibrated rows subtract wrapper letter bias measured by removing the question and option text.

The mechanistic claim tested here is narrower. These experiments do not show a simple internal activation vector that can be copied from successful wrapper runs into failed wrapper runs. Attention diagnostics do not separate successful from failed wrapped prompts. Similarity to the unwrapped prompt is directionally consistent but very small. Patching improves some failed runs, but the strongest effects are entangled with answer-letter structure and cross-item donors. The safest interpretation is that wrapper robustness is mixed with answer formation rather than isolated in a reusable formatting-removal vector.

The scope is limited in several ways. The study uses three instruction-tuned checkpoints from three model families, but still only one multiple-choice dataset and eight wrappers. Model size and family are not varied independently. The wrappers were intended as pure-interface transformations, but the audit found a small number of content-changing cases, and even content-preserving wrappers can interact with pretraining priors in ways that are not neutral for the model. The mechanistic probes use coarse token roles and two semantic anchors; a finer circuit analysis could find structure that these tests miss. The patching controls are also not proof that answer-letter information is the only thing transferred. They show that the observed patching effects are not clear evidence for the simpler hypothesis.

The practical implication is two-sided. Interface sensitivity is a reliability problem for systems that route model inputs through tools or structured records, and wrapper tests could expose these failures before deployment. The same evidence could also help construct brittle or adversarial interfaces. The main mitigation is to evaluate wrapper robustness directly and to avoid treating small patching improvements as circuit-level explanations.

\section{Conclusion}

Changing the intended interface wrapper around an MMLU question can change whether Qwen2.5-1.5B, Phi-3.5-mini, and Mistral-7B-v0.3 answer correctly. The study finds this instability under calibrated answer-letter scoring across 72,000 prompts, and the audit sensitivity analysis shows that it remains after identified defects are removed. It does not find evidence for the simplest mechanistic account: a reusable internal activation vector that strips away formatting and identifies the real task. The useful result is the negative one. Wrapper failures generalize across these model families, but in this setting they appear entangled with answer formation, and causal patching needs strong controls before it can support mechanistic claims.
