# Project Agent Instructions

- Keep work in small, coherent commits at logical checkpoints and push each verified checkpoint to `origin` promptly. Do not commit after every edit; commit when one reviewable unit is complete and its focused checks pass.
- Before staging, inspect the worktree and include only changes that belong to the active task. Preserve unrelated user or parallel-worker changes.
- If authentication, network access, or a failing validation blocks a commit or push, report the blocker immediately instead of silently accumulating a large unpublished diff.
